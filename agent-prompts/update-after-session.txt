# Update Prompts After Your Session

This file is a checklist for updating agent prompts after you finish your work.

**Do this BEFORE committing and pushing.**

## Checklist

### Step 1: Update `next-session.txt`

**Find this section:**
```
## WHAT WAS DONE IN PREVIOUS SESSION
- Session 1: Redis + Docker ✅
- Session 2: Local Dev Strategy ✅
```

**Update it to include what YOU did (add new session):**
```
## WHAT WAS DONE IN PREVIOUS SESSION

### Session 1 (Scalability Setup) - COMPLETED ✅
- Added Redis Adapter to Socket.io
- Optimized Dockerfile
- Created documentation

### Session 2 (Local Dev Strategy) - COMPLETED ✅
- Created LOCAL_DEV_STRATEGY.md
- Documented 3 deployment approaches
- Updated START_HERE.md navigation

### Session 3 (YOUR SESSION NAME HERE) - COMPLETED ✅
- Added JWT authentication
- Implemented photo upload to S3
- Setup monitoring
```

### Step 2: Update the 5 Paths (IMPORTANT!)

**Current state:**
- PATH 1: SET UP LOCAL DEV WITH REAL AWS SERVICES (NEW)
- PATH 2: IMPLEMENT JWT AUTHENTICATION  
- PATH 3: DEPLOY TO PRODUCTION
- PATH 4: LOCAL TESTING & VERIFICATION
- PATH 5: CONTINUE FROM CONTEXT

**After completing work, update to reflect reality:**
```
### PATH 1: SET UP LOCAL DEV WITH REAL AWS SERVICES ✅ COMPLETED IN SESSION 3
(Can remove or keep as reference)

### PATH 2: IMPLEMENT JWT AUTHENTICATION ✅ COMPLETED IN SESSION 3
(Remove if done)

### PATH 3: DEPLOY TO PRODUCTION ← READY FOR NEXT AGENT
(Recommend deploying now that JWT is done)

### PATH 4: ADD PHOTO UPLOAD SYSTEM (3-4 hours) ← NEXT PRIORITY
(Was PATH 1, now move to higher priority)

### PATH 5: LOAD TESTING & PERFORMANCE (6-8 hours)
(New path based on project stage)
```

### Step 4: Commit Changes

```bash
git add agent-prompts/
git commit -m "chore: update agent prompts after Session 3 - JWT & S3 integration complete"
git push
```

## Tips for Good Updates

1. **Be specific** - Write what was actually done, not generic descriptions
2. **Include times** - "4.5 hours for JWT" helps future estimates
3. **Mark as done** - Use ✅ for completed work
4. **Add challenges** - Note any blockers for next session
5. **Reorder paths** - Put completed tasks at top, next priority clearly marked
6. **Add new paths** - If you discovered new needed work, add as PATH 6, 7, etc.
